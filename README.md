# Football Match Predictor (Poisson Model)

**Applied Programming Projects** — University of Basel  
*Instructor: Lukas Rosenthaler*

## Project Overview
This project predicts football match outcomes based on historical data using a statistical Poisson distribution model (Dixon-Coles) and presents predictions via an interactive Streamlit web dashboard.
